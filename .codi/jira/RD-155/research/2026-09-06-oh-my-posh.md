# Oh My Posh

## Hallazgos

- Motor de prompts cross-platform escrito en Go; funciona en 8+ shells (bash, zsh, fish, PowerShell, Nushell, Elvish, Xonsh, CMD) y cualquier SO.
- Un solo binario en el PATH; una única config para todos los shells.
- Instalación Linux: curl -s https://ohmyposh.dev/install.sh | bash -s (instala en ~/bin o ~/.local/bin; flags -d <dir> y -v <version>).
- Config en JSON/YAML/TOML con JSON Schema oficial; estructura de blocks → segments → templates (Go text/template); estilos powerline, plain, diamond, accordion.
- Integración zsh: eval "$(oh-my-posh init zsh --config <path>)"; soporta --strict, live reload y preview.
- 117+ segments (git, path, status, node, python, docker, kubectl, aws...); git segment con background_templates dinámicos, mapped_branches, fetch_status; paletas de colores; transient/secondary prompt; async mode; caché por segmento; oh-my-posh debug para cuellos de botella.
- Comparativa: cross-shell vs P10k/Pure (solo Zsh); más segments que Starship (~50) pero config más compleja que TOML plano; Starship más rápido en repos grandes. Requiere Nerd Fonts obligatorio.
