## Contenido Fuente

### Scenario

Archify es un sistema Node.js que convierte codebases o descripciones de sistemas en diagramas de arquitectura interactivos. Genera SVG/HTML deterministicamente desde JSON tipado. Soporta 5 tipos de diagrama (Architecture, Workflow, Sequence, Data Flow, Lifecycle), tracing de rutas, historias guiadas y share cards. Funciona con agentes de IA como Cursor, Claude Code, Codex CLI y OpenCode. Licencia MIT, versión actual 2.17.0-dev.0. Se instala como skill de agente via bunx skills add.

## Implementación en zsh/modules/ai/

### Resumen

Archify se integra como un skill de agente más en el módulo AI, siguiendo el patrón establecido por las 14 herramientas existentes. La integración toca 3 capas: config, internal, y pkg.

### Archivos a crear/Modificar

#### 1. Nuevo: `config/archify.zsh`

```zsh
# Archify — Architecture diagram generator
ZSH_AI_ARCHIFY_BIN="${HOME}/.local/bin"
ZSH_AI_ARCHIFY_INSTALL_URL="https://raw.githubusercontent.com/tt-a1i/archify/main/install.sh"
ZSH_AI_ARCHIFY_SKILL_REPO="tt-a1i/archify"
```

#### 2. Nuevo: `internal/archify.zsh`

Funciones requeridas:
- `ai::internal::archify::load` — Agregar `${ZSH_AI_ARCHIFY_BIN}` a `$PATH`
- `ai::internal::archify::install` — Instalar via `bunx skills add tt-a1i/archify -g` (verificar `core::exists archify` primero)
- `ai::internal::archify::setup` — Ejecutar `archify doctor` para verificar instalación

Patrón a seguir: `internal/hunk.zsh` o `internal/openspec.zsh` (instalación simple vía package manager).

#### 3. Nuevo: `pkg/archify.zsh`

API pública:
```zsh
ai::archify::install   # Instalar Archify
ai::archify::doctor    # Verificar salud de la instalación
ai::archify::render    # Wrapper: archify render "$@"
ai::archify::validate  # Wrapper: archify validate "$@"
ai::archify::deliver   # Wrapper: archify deliver "$@"
```

#### 4. Modificar: `config/skills.zsh`

Agregar `tt-a1i/archify` al array de repos de skills para que `ai::skills::setup` lo instale automáticamente.

#### 5. Modificar: `config/base.zsh`

Agregar `"archify"` al array `ZSH_AI_TOOLS` para que el batch installer lo reconozca.

#### 6. Nuevo (opcional): `pkg/alias.zsh` — agregar alias

```zsh
alias archify-render='archify render'
alias archify-validate='archify validate'
alias archify-deliver='archify deliver'
alias archify-doctor='archify doctor'
```

### Requisitos previos

- Node.js >= 18 (ya requerido por otras herramientas)
- `bunx` disponible (viene con Node.js)
- `bunx` para instalación de skills

### Casos de uso para proyectos Codip

1. **Documentación de arquitectura** — Generar diagramas de arquitectura desde descripciones en issues de Jira
2. **Code review visual** — Usar `archify compare architecture` para ver deltas en PRs
3. **Onboarding** — Generar diagramas interactivos de sistemas existentes para nuevos miembros del equipo
4. **Share cards** — Generar imágenes 1200×630 para READMEs y documentación
5. **Presentaciones** — Usar modo presentación para demos de arquitectura

### Validación

1. Ejecutar `ai::archify::install` y verificar que `archify --version` retorne la versión
2. Ejecutar `archify doctor` para verificar salud
3. Generar un diagrama de demo: `archify demo /tmp/archify-test`
4. Verificar que el diagrama se genera correctamente en HTML
