# PE-313: Migrar colecciones Postman de NexoAgentes a formato Bruno en api-catalog

## Contenido Fuente

### Scenario

NexoAgentes dispone de 6 colecciones Postman con 56 endpoints documentados que describen la integración con NexoInmobiliario. El repositorio api-catalog (https://github.com/CodipLab/api-catalog) utiliza Bruno como herramienta de testing de APIs. Se requiere migrar todas las colecciones Postman al formato Bruno, manteniendo la estructura de módulos, la autenticación por tokens, y los tests existentes.

### Acceptance Tests

- [ ] Colecciones Postman importadas y convertidas a formato .bru
- [ ] Estructura de módulos preservada (Agentes, Auth, Builder, Citas, Comisión, Contacto, Imagen, Minutas, Proyectos, Unidades, Capacitaciones, Modelos, Usuario, Tipo de Cambio)
- [ ] Variables de entorno configuradas en Bruno (baseUrl, authToken)
- [ ] Headers de autenticación correctamente mapeados (Bearer token con builder_id)
- [ ] Request bodies JSON preservados
- [ ] Tests de respuesta añadidos a cada endpoint
- [ ] Documentación en bloque docs de cada .bru con descripción del endpoint
- [ ] Environment file de Bruno creado (AgentesApi)
- [ ] README de la collection actualizado con instrucciones de uso
