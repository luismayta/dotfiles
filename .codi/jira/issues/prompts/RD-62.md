# RD-62: Crear módulo smolvm siguiendo la guía de creación de módulos

## Contenido Fuente

### Scenario

Crear un nuevo módulo zsh con el nombre `smolvm` en `zsh/modules/`, siguiendo la guía de creación de módulos del repositorio (`docs/guides/create-module.md`), que documenta la arquitectura tri-capa `config/`, `internal/`, `pkg/` más `data/` y el entry point `plugin.zsh`.

El módulo debe gestionar la herramienta `smolvm` (microVM engine de smol-machines, Apache-2.0) que el plugin herdr `smolbox` (carze/herdr-smolmachine) usa para correr coding agents en microVMs efímeras. La adopción decidida: pin **smolvm 1.3.2** (versión validada por el plugin), binario en `~/.local/bin`, KVM ya verificado funcional en el host (CachyOS, `/dev/kvm` 666 + flag vmx).

Referencia de estructura existente: módulo `zsh/modules/herdr/` (mismo patrón: `plugin.zsh` como único punto de carga, `config/main.zsh` → `internal/main.zsh` → `pkg/main.zsh`, guard de idempotencia, enable/disable vía variable `ZSH_SMOLVM_ENABLED`).

### Acceptance Tests

- Estructura del módulo creada en `zsh/modules/smolvm/` con `plugin.zsh`, `config/`, `internal/`, `pkg/` y `data/` según `docs/guides/create-module.md`
- `plugin.zsh` es el único archivo sourceado por zshrc; encadena `config/main.zsh` → `internal/main.zsh` → `pkg/main.zsh` con guard de idempotencia (`__ZSH_SMOLVM_LOADED`)
- Módulo deshabilitable: si `ZSH_SMOLVM_ENABLED != true`, no se carga (patrón del módulo herdr)
- Instalación de `smolvm` v1.3.2 en `internal/install.zsh`: descarga del release oficial, verificación de checksum SHA256, instalación en `~/.local/bin`, `core::ensure` de dependencias
- Verificación post-instalación: `smolvm --version` reporta 1.3.2 y `smolvm machine run --help` responde
- `bash -n` y shellcheck limpios en todos los archivos nuevos del módulo
- `README.md` del módulo generado desde el template compartido (`provision/templates/README.module.tpl.md`)

`zsh/modules/herdr/` reference pattern (source of truth for the module shape):

- `plugin.zsh` — `# shellcheck shell=bash`; idempotency guard `[[ -n "${__ZSH_HERDR_LOADED:-}" ]] && return`; `__ZSH_HERDR_LOADED=1`; `ZSH_HERDR_PATH="$(dirname "${0}")"`; `message_info "Loading module: ${ZSH_HERDR_PACKAGE_NAME:-herdr}"`; sources `config/main.zsh`; `${ZSH_HERDR_ENABLED:-false} || return`; sources `internal/main.zsh`; `core::path::prepend "${ZSH_HERDR_PATH}/bin"`; sources `pkg/main.zsh`; auto-install guards after pkg (e.g. `if ! core::exists rsync; then core::install rsync; fi`)
- `config/main.zsh` — sources `config/base.zsh` (+ extra layer files), then OS dispatch `case "${OSTYPE}" in darwin*) .../osx.zsh ;; linux*) .../linux.zsh ;; esac`
- `config/base.zsh` — env vars with `ZSH_<NAME>_` prefix, all exported: `ZSH_<NAME>_ENABLED="${ZSH_<NAME>_ENABLED:-true}"`, `ZSH_<NAME>_PACKAGE_NAME`, `ZSH_<NAME>_INSTALL_URL`, `ZSH_<NAME>_CONFIG_PATH="${HOME}/.config/<name>"`, `ZSH_<NAME>_DATA_PATH="${ZSH_<NAME>_PATH}/data"`
- `internal/main.zsh` — sources layer files in dependency order (base → install → ...), OS dispatch, `core::ensure curl`, auto-install: `if ! core::exists herdr; then herdr::internal::install; fi`
- `internal/install.zsh` — `herdr::internal::install()`: early-return if `core::exists herdr`; `core::ensure curl`; `message_info`/`message_success`/`message_warning`/`message_error` for all output; `curl -fsSL "${ZSH_HERDR_INSTALL_URL}" | sh`; verify binary in PATH after install; `herdr::internal::config::sync()`: rsync `data/` → config path with empty-dir guard
- `pkg/main.zsh` — sources `pkg/base.zsh`, OS dispatch, `pkg/helper.zsh`, `pkg/alias.zsh`
- `pkg/base.zsh` — public wrappers `<name>::install`, `<name>::sync`, `<name>::post_install`
- `pkg/helper.zsh` — `<name>::setup()` orchestrator: install if missing else info, then sync, success message
- Module files present: `bin/`, `config/` (base.zsh linux.zsh main.zsh osx.zsh plugins.zsh), `data/`, `internal/` (base.zsh install.zsh linux.zsh main.zsh osx.zsh pane.zsh update.zsh workspace.zsh worktree.zsh), `pkg/` (alias.zsh base.zsh helper.zsh linux.zsh main.zsh osx.zsh), `README.md`, `README.yaml`, `Taskfile.yml`, `plugin.zsh`
