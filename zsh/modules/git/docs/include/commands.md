## Commands Reference

| Alias | Command | Description |
|-------|---------|-------------|
| `gst` | `git status` | Show working tree status |
| `gco` | `git checkout` | Switch branches |
| `gbr` | `git branch` | List branches |
| `glg` | `git log --oneline --graph` | Compact commit log |
| `gdf` | `git diff` | Show diff |
| `gpl` | `git pull` | Pull from upstream |
| `gps` | `git push` | Push to origin |
