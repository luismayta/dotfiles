The git module loads automatically via the zsh module loader. All aliases and
functions are available immediately after the module is sourced.

### Quick start

```zsh
# Status
gst          # git status

# Checkout
gco main     # git checkout main

# Branches
gbr          # git branch
gbr -a       # git branch -a (all branches)

# Log
glg          # git log --oneline --graph
glg -10      # last 10 commits
```
