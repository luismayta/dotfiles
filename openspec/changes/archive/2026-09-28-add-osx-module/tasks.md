# Tasks

> **Nota sobre verificación.** Este repo **no tiene harness de tests de zsh**: no hay bats, ni shunit2, ni `zsh/modules/*/test*`. Los hooks de pre-commit son do-not-commit, shellcheck, codespell, check-json, check-yaml, lychee, luacheck, stylua y luac-check — ninguno es un runner de tests de shell. La verificación de cada grupo es, por lo tanto, exactamente tres cosas: (a) `shellcheck --exclude=SC1072,SC1073,SC2068,SC1091 <los archivos del grupo>` — el quality gate real, que el hook corre sobre `zsh/modules/**` sin exclusión alguna —, (b) aserciones de runtime dirigidas con `source`, `type` y salida esperada, al estilo de la sección *Migration Plan* del design, y (c) artefactos entregados que se pueden inspeccionar. No busques un runner de tests que no existe; cada tarea dice abajo cómo se verifica en este repo.
